2. สินค้าคงคลังและแบบจำลองเสมือนจริงด้วย Plant Simulation

ทฤษฎี : ปฏิบัติ = 2 : 7 ชั่วโมง

หัวใจของหลักสูตร: คำนวณสินค้าคงคลัง แล้วสร้างแบบจำลองคลังสินค้าใน Plant Simulation 2504 ด้วยตัวเอง ตั้งแต่คลังเปล่าจนถึงระบบอัตโนมัติ — คน, Forklift, AGV, AMR, AS/RS (Library HBW) และโรงงาน / คลังสินค้า 3D

2.1

สินค้าคงคลัง และแบบจำลองเสมือนจริง

ทฤษฎี · ABC, EOQ, Safety Stock, ROP, การจัดวางสินค้า และ Object ใน Plant Simulation ที่แทนอุปกรณ์จริง
2.2

สร้างคลังสินค้าแรก

ปฏิบัติ · เพิ่ม Library HBW วาด Conveyor วาง RackLane + WMS รัน 8 ชม. หาคอขวด แล้วฝึกแก้ 3 ปัญหา: sensor userSetTarget, RSU 2 m/s, คลังเต็ม
2.3

ป้อนข้อมูลสินค้าเข้า – ออก, Method และการแสดงข้อมูลสินค้าคงคลัง

ปฏิบัติ · HBW H05–H12: รอบการนำออก สินค้า 2 ชนิด กลยุทธ์จัดเก็บ 4 แบบ Method Init / OrderControl และสถิติ RSU เมื่อเครื่องเสีย
2.4

คน และกะทำงาน (Workers & Shifts)

ปฏิบัติ · Workplace / WorkerPool / Broker จำนวนคน ความเร็ว กะทำงาน ผัง I กับ U คนขนของ ช่างตั้งเครื่อง และช่างซ่อม (94 → 356 ชิ้น/ชม.)
2.5

ระบบขนถ่ายในคลังสินค้าอัตโนมัติ

ทฤษฎี · คน, Forklift, AGV, AMR, AS/RS และ 3D — แต่ละแบบใช้ Object อะไร และวัดผลอะไร
2.6

Track และ Transporter (AGV)

ปฏิบัติ · วาด Track วงปิดให้รถ Transporter วิ่ง ใช้ PickAndPlace โหลด / ขนถ่ายชิ้นงานโดยไม่เขียน Method และ TwoLaneTrack รถวิ่งสวน 2 เลน
2.7

AMR ด้วย AGVPool และ GAWizard

ปฏิบัติ · AMR วิ่งอิสระด้วย AGVPool + Marker สั่งรถด้วย Method หาจำนวนรถที่พอดี แล้วใช้ GAWizard หาเส้นทางที่สั้นที่สุด
2.8

3D Factory and Warehouse

ปฏิบัติ · สร้างผนัง ชั้นวาง ชั้นลอย บันได นำเข้าไฟล์ 3D ติดโลโก้บนผนัง และวางผัง DWG โปร่งแสงใต้แบบจำลอง
