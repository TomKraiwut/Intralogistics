0.2 โหลดไฟล์ตัวอย่างของหลักสูตร

เริ่มต้น: ติดตั้งโปรแกรม · ภาคปฏิบัติ

วัตถุประสงค์การเรียนรู้

  1. ดาวน์โหลดไฟล์ตัวอย่างของหลักสูตรจาก Google Drive
  2. เก็บไฟล์ไว้ในโฟลเดอร์ที่โปรแกรมเปิดได้โดยไม่มีปัญหา
  3. เปิดไฟล์โมเดลใน Plant Simulation 2504 เพื่อทดสอบว่าพร้อมเรียน
⬇ เปิดโฟลเดอร์ไฟล์ตัวอย่าง (Google Drive)

โฟลเดอร์ 01_Training_Model — เปิดดูได้โดยไม่ต้องล็อกอิน

1. ดาวน์โหลดไฟล์

  1. 1คลิกปุ่ม เปิดโฟลเดอร์ไฟล์ตัวอย่าง ด้านบน
  2. 2ดาวน์โหลดทั้งโฟลเดอร์: คลิกชื่อโฟลเดอร์ 01_Training_Model ด้านบนของหน้า แล้วเลือก Download — Google Drive จะรวมไฟล์เป็น .zip ให้ (ถ้าไฟล์ใหญ่อาจได้หลาย zip)
  3. 3ถ้าต้องการบางไฟล์: คลิกขวาที่ไฟล์นั้นแล้วเลือก Download

2. เก็บไฟล์ในโฟลเดอร์ที่ถูกต้อง

  1. 1สร้างโฟลเดอร์ C:\PtS_Intralogistics
  2. 2แตกไฟล์ .zip (คลิกขวา → Extract All…) ลงในโฟลเดอร์นี้
  3. 3ตรวจว่าไฟล์ .spp กับไฟล์ข้อมูล (เช่น Excel) ที่มาด้วยกันอยู่ในโฟลเดอร์เดียวกัน
ระวัง: อย่าเปิดไฟล์จากในไฟล์ .zip โดยตรง และอย่าเก็บไว้ในโฟลเดอร์ที่ชื่อมีภาษาไทย — แบบจำลองที่อ่านไฟล์ข้อมูลจะหาไฟล์จากโฟลเดอร์ของตัวเอง ถ้าแยกไฟล์ไว้คนละที่จะอ่านข้อมูลไม่ได้

3. เปิดโมเดลทดสอบ

  1. 1เปิด Plant Simulation 2504
  2. 2คลิกเมนู File → Open แล้วเลือกไฟล์ .spp ในโฟลเดอร์ C:\PtS_Intralogistics
  3. 3ดับเบิลคลิก Frame ใน Class Library › Models เพื่อดูแบบจำลอง
ไฟล์ทุกไฟล์บันทึกด้วย Plant Simulation 2504: เปิดด้วยเวอร์ชัน 2504 หรือใหม่กว่าได้ แต่ถ้าบันทึกทับด้วยเวอร์ชันใหม่กว่า จะเปิดกลับใน 2504 ไม่ได้ — ระหว่างเรียนให้ใช้ 2504 เท่านั้น

4. ไฟล์ในโฟลเดอร์

ไฟล์จะทยอยเพิ่ม: ไฟล์ของแต่ละบทจะเพิ่มเข้าโฟลเดอร์เดิมก่อนวันอบรม ใช้ลิงก์เดิมได้ตลอด — ก่อนวันอบรมให้ดาวน์โหลดอีกครั้งเพื่อให้ได้ไฟล์ครบ
